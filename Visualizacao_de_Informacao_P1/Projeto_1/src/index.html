A NOTE ON THE DATA

Data & methodology

406 records from the course file cars_alterado.csv. Weight is in pounds and power in horsepower. The acceleration field is interpreted as time in seconds, consistent with the Auto MPG family of datasets; the supplied file has no data dictionary. Values were modified during the original assignment, including missing horsepower values. No further corrections have been made to the source file.
